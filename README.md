# She4Tech SDG Inquiry System

## Project Description
This project is a simple C++ inquiry management system created for the She4Tech SDG Project. It allows users to add, view, and search inquiries using a menu-driven program.

## Features
- Add Inquiry
- View All Inquiries
- Search Inquiry by ID
- Simple Console Interface

## Programming Language
- C++

## How to Run
1. Open the project in an online C++ compiler or IDE.
2. Copy and paste the code into `main.cpp`.
3. Compile and run the program.
4. Use the menu to manage inquiries.
